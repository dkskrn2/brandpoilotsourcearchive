# AI 콘텐츠 릴스 BGM 합성 설계

## 목표

이미지 워커가 신규 AI 콘텐츠 릴스 MP4를 합성할 때 지정된 BGM을 영상 시작부터 재생하고 영상 길이에서 정확히 자른다. 음원 나머지는 사용하지 않는다.

## 승인 범위

- 적용 경로: `brand-pilot-image-worker`의 신규 AI 콘텐츠 릴스 합성 경로만
- 제외 경로: 카드뉴스, 이미지 생성, 원고·구성안 생성, API 게시 동작, UI 화면·기능, DB
- 장면 시간: 장면당 3초 유지
- BGM 볼륨: 12%
- 시작·종료 페이드: 각각 0.5초
- 입력 음원: `mixkit-a-very-happy-christmas-897.mp3`
- 원본 SHA-256: `714BAA43F1C04E8CA77A8268825EA7E68E958917F5F5FE4C656D83811E1D0C98`

## 검토한 접근

1. **이미지 워커에 음원을 정적 자산으로 포함 — 채택**
   - 외부 네트워크 없이 항상 같은 음원을 사용한다.
   - 워커 이미지 크기가 약 4.2MB 증가하지만 생성 안정성이 가장 높다.
2. 실행할 때마다 외부 URL에서 다운로드
   - 저장소 크기는 늘지 않지만 외부 URL·네트워크 장애가 릴스 생성을 실패시킬 수 있어 제외한다.
3. 게시 단계에서만 BGM 합성
   - 완료 화면의 미리보기와 실제 게시물이 달라지고 API 게시 범위까지 확대되어 제외한다.

## 데이터 흐름

1. 이미지 워커 컨테이너에 검증된 MP3 정적 자산을 포함한다.
2. 신규 AI 콘텐츠 릴스 렌더러가 장면 PNG와 함께 해당 MP3 경로를 FFmpeg 합성 스크립트에 전달한다.
3. FFmpeg는 음원을 반복하지 않고 처음부터 읽는다.
4. `atrim`으로 완성 영상 길이만 남기고 볼륨과 시작·종료 페이드를 적용한다.
5. MP4는 H.264 영상 1개와 AAC 음성 1개를 포함한다.
6. 이미지 워커는 실제 출력에 영상 1개·음성 1개, H.264/AAC, 30fps, 1080×1920, 예상 재생 시간이 맞는지 검사한다.
7. 검증된 MP4만 기존 Blob 저장·완료 처리로 전달한다.

## 계약과 호환성

- 신규 이미지 워커 출력은 `audioCodec: "aac"`를 사용한다.
- 공용 manifest와 API 읽기 검증은 `audioCodec: null | "aac"`를 허용한다.
- 기존 무음 완료 릴스(`null`)는 조회·다운로드·게시할 수 있다.
- 신규 워커 생성은 AAC를 필수로 검증한다. 음원이 없거나 손상됐거나 AAC 트랙이 없으면 무음으로 우회하지 않고 렌더 실패로 처리한다.
- JSON 필드 추가나 DB 저장 구조 변경이 없으므로 DB migration은 없다.
- 고객 UI는 공유 manifest parser를 포함하므로 화면 변경 없이 새 `aac` 값을 읽을 수 있도록 함께 다시 빌드한다.

## 오류 처리

- 패키징된 MP3가 없거나 SHA-256이 다르면 이미지 워커 빌드 또는 시작 전 검증을 실패시킨다.
- FFmpeg가 음원을 읽지 못하거나 AAC 합성에 실패하면 해당 릴스 렌더를 실패시킨다.
- 영상보다 음원이 짧은 경우에는 무음 꼬리를 만들지 않는다. 현재 승인 음원은 약 130초이고 최대 신규 릴스는 15초이므로 정상 운영 범위에서는 발생하지 않는다.
- 기존 완료 릴스는 재합성하지 않는다.

## 예상 변경 범위

- 이미지 워커 정적 BGM 자산 및 Docker 패키징
- 신규 AI 콘텐츠 릴스 렌더러와 FFmpeg 스크립트
- 이미지 워커 finalizer/storage의 `audioCodec` 타입
- 공용 manifest 계약과 API manifest 읽기 검증의 `null | "aac"` 호환
- 관련 단위·통합·실제 FFmpeg 검증

## 검증 기준

- 1장 릴스: 3초, 1080×1920, 30fps, H.264 + AAC
- 5장 릴스: 15초, 1080×1920, 30fps, H.264 + AAC
- 음원이 영상 시작점에서 시작하고 영상 종료점에서 끝남
- 종료 후 원본 음원 나머지가 포함되지 않음
- BGM 누락 시 신규 렌더 실패
- 기존 `audioCodec: null` manifest 조회·다운로드·게시 성공
- 신규 `audioCodec: "aac"` manifest 조회·다운로드·게시 성공
- 카드뉴스와 DB 변경 없음

## 배포 경계

운영 배포는 별도 사용자 승인 전 수행하지 않는다. 이후 배포 대상은 API, 고객 UI, 이미지 워커다. 고객 UI는 화면 변경이 아니라 새 manifest parser 반영을 위한 재빌드이며, 다른 워커와 DB는 배포 대상에 포함하지 않는다.
