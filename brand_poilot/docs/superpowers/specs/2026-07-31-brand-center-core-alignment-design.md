# 브랜드센터 브랜드 코어 정합화

## 목표

온보딩 분석 검토에서 확정한 브랜드 코어와 브랜드센터의 표시·수정 항목을 동일하게 맞춘다.

## 확정 항목

브랜드센터는 다음 7개 항목만 표시한다.

1. 기업 개요
2. 사업 소개
3. 대표 분야
4. 직접 입력 세부 분야
5. 핵심 타깃
6. 차별점
7. 핵심 소구점

기존 `한 줄 소개`, `핵심 가치`, `브랜드 방향성`, `근거 N개 확인` UI는 제거한다. 근거 데이터 자체는 삭제하지 않는다.

## 데이터 호환

`brand-core.v1` 계약에 7개 정규 필드를 하위 호환 속성으로 추가한다. 기존 저장 행에 정규 필드가 없으면 기존 중첩 필드에서 값을 변환해 읽는다. 현재 승인 분석과 연결된 활성 버전은 분석 결과의 7개 값을 우선 적용하여 기존 잘못된 중복 매핑을 바로잡는다.

새 분석 확정과 사용자 수정은 정규 필드와 기존 소비자용 중첩 필드를 함께 저장한다. 따라서 기존 콘텐츠·DM 소비자는 깨지지 않고 브랜드센터는 온보딩과 동일한 값을 사용한다.

## 화면

온보딩 검토 폼과 동일한 라벨, 입력 테두리, 전체 너비, 세로 간격을 사용한다. 긴 텍스트는 한 열 전체 너비로, 대표 분야와 직접 입력 세부 분야는 데스크톱에서 두 열·모바일에서 한 열로 배치한다. 승인 버전은 읽기 전용이고 수정 초안에서만 입력할 수 있다.

## 검증

- 7개 항목만 렌더링되는지 확인한다.
- 기존 세 항목과 근거 드로어가 렌더링되지 않는지 확인한다.
- 기존 v1 데이터와 현재 분석 연결 데이터가 모두 정규 필드로 변환되는지 확인한다.
- 수정·저장·승인 흐름과 충돌 복구가 유지되는지 확인한다.
- 고객 UI와 API 테스트·빌드를 통과한 후 운영 배포 상태와 실제 페이지를 확인한다.
