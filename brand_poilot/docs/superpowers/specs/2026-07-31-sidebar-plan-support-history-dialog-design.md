# 사이드바 플랜 표시 및 문의 내역 팝업 설계

## 목표

- 사이드바 프로필의 보조 문구에 현재 구독 플랜명을 표시한다.
- 구독 정보가 없거나 응답이 비정상적이거나 조회가 실패하면 `FREE 플랜`을 표시한다.
- 브랜드 센터 하단의 `문의 내역`을 제거하고, 사이드바 프로필 드롭다운에서 팝업으로 열 수 있게 한다.
- 기존 API만 조회하며 API·DB·서버 계약은 변경하지 않는다.

## 화면과 상태 소유

`AppShell`이 플랜 라벨과 문의 내역 팝업 상태를 한 번만 관리한다.

- 기존 `getBillingSummary` 응답의 `subscription.planName`이 비어 있지 않으면 그대로 표시한다.
- 응답 속성이 없거나 값이 비었거나 요청이 실패하면 `FREE 플랜`을 유지한다.
- 데스크톱·모바일 사이드바에 같은 플랜 라벨과 `문의 내역` 열기 콜백을 전달한다.
- 모바일에서는 프로필 드롭다운과 사이드바를 먼저 닫은 뒤 문의 내역 팝업을 연다.

프로필 드롭다운 순서는 다음과 같다.

1. 브랜드센터
2. 플랜
3. 문의 내역
4. 로그아웃

## 문의 내역 팝업

기존 `SupportRequestHistory`의 데이터 조회·로딩·오류 재시도·답변 펼치기 동작을 재사용한다. 팝업에서는 중복 제목을 피하기 위해 본문형 표시를 지원하고, 독립된 문의 페이지에서의 기존 패널 표시는 유지한다.

팝업은 기존 피드백 팝업과 같은 상호작용을 따른다.

- 닫기 버튼, 배경 클릭, `Escape`로 닫기
- 팝업 내부 포커스 유지
- 닫을 때 실행 버튼으로 포커스 복원
- 열려 있는 동안 배경 스크롤 차단
- 모바일 화면에서는 화면 너비에 맞는 전체 높이 패널 사용

## 브랜드 센터

브랜드 센터 하단의 `SupportRequestHistory` 렌더링과 해당 import만 제거한다. 고객 지원 페이지의 문의 내역은 변경하지 않는다.

## 검증

- 구독 플랜명이 있으면 해당 값이 사이드바에 표시된다.
- 구독 없음, 누락된 응답, 조회 실패에서는 `FREE 플랜`이 표시된다.
- 프로필 드롭다운에 네 메뉴가 지정 순서로 표시되고 `문의 내역`이 팝업을 연다.
- 데스크톱과 모바일에서 팝업 열기·닫기·포커스 복원이 동작한다.
- 모바일에서는 사이드바가 닫힌 다음 팝업이 열린다.
- 브랜드 센터에는 문의 내역 영역이 더 이상 렌더링되지 않는다.
- 고객 지원 페이지의 기존 문의 내역 동작은 유지된다.

## 제외 범위

- API 엔드포인트, API 응답 타입, DB 스키마 및 서버 구현 변경
- 결제 페이지 자체의 변경
- 운영 배포
