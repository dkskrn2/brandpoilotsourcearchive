# 자동 게시 토글 UI 설계

## 목표

게시관리 캘린더 헤더의 `자동 게시 설정` 버튼을 자동 게시 활성화 상태를 바로 바꾸는 토글과 설정 팝업을 여는 `수정` 버튼으로 분리한다. 자동 게시 활성화의 조작점은 헤더 토글 하나로 통일하고, 팝업에서는 게시 시간과 추천별 콘텐츠 형식만 편집한다.

## 범위

- 고객 UI의 게시관리 캘린더 헤더와 기존 자동 게시 설정 팝업만 변경한다.
- 기존 `PublishCalendarSettings` 모델과 `PUT /brands/:brandId/publish-calendar/settings` API를 그대로 사용한다.
- API, DB, worker, 자동 배정 로직은 변경하지 않는다.
- 이번 작업은 구현과 로컬 검증까지만 수행하고 배포하지 않는다.

## UI 구조

캘린더 헤더의 기존 버튼 자리에 다음 순서로 컨트롤을 배치한다.

1. `자동 게시` 텍스트
2. 현재 상태를 나타내는 `role="switch"` 토글과 `ON` 또는 `OFF` 상태 문구
3. 기존 설정 팝업을 여는 `수정` 버튼
4. 기존 이전 달·다음 달 버튼

토글은 `aria-checked`로 서버에서 받은 `settings.enabled`를 표현한다. `수정` 버튼이 팝업을 연 뒤 닫히면 포커스는 `수정` 버튼으로 돌아온다.

기존 팝업에서는 활성화 스위치와 활성화 설명을 제거한다. 게시 채널 상태, 게시 시간, 정보성 추천 형식, 트렌드성 추천 형식, 저장·취소 동작은 유지한다. 팝업 저장은 현재 활성화 상태를 변경하지 않는다.

## 데이터 흐름

### 헤더 토글

토글을 누르면 현재 설정의 시간과 형식은 그대로 두고 다음 payload를 기존 저장 API로 보낸다.

- 켜기: `enabled: true`, `channels: ["instagram"]`
- 끄기: `enabled: false`, `channels: []`
- `informationalFormat`, `trendFormat`, `slotTimes`: 현재 서버 설정값 유지

서버 응답이 성공한 뒤 부모의 `calendarSettings`를 갱신하므로 토글은 서버가 확정한 상태를 표시한다. 저장 중에는 중복 요청을 막기 위해 토글과 `수정` 버튼을 비활성화한다.

### 팝업 수정

팝업 저장 payload의 `enabled`와 `channels`는 팝업을 열 때 받은 현재 설정값을 그대로 사용한다. 사용자는 팝업에서 게시 시간과 두 추천 형식만 바꿀 수 있다.

## 상태와 오류 처리

- 설정 로딩 중 또는 설정 조회 실패 시 토글을 비활성화한다.
- 설정 조회 실패 상태에서도 `수정` 버튼은 기존 읽기 전용 오류 팝업을 연다.
- Instagram이 연결되지 않았으면 꺼진 토글을 켤 수 없다.
- Instagram 연결이 끊긴 상태라도 켜진 토글은 끌 수 있어야 한다.
- 토글 저장 실패 시 표시 상태를 바꾸지 않고 헤더 가까이에 `role="alert"` 오류를 표시한다.
- 팝업 저장 실패는 기존 팝업 내부 오류 표시를 유지한다.
- 자동 게시를 꺼도 기존 예약은 유지한다는 기존 동작과 안내를 보존한다.

## 테스트

고객 UI 테스트에 다음 동작을 추가하거나 기존 테스트를 변경한다.

1. 서버의 enabled 값에 따라 헤더 토글이 ON/OFF와 `aria-checked`를 표시한다.
2. 토글 ON/OFF가 기존 설정값을 보존한 payload로 저장 API를 호출한다.
3. 연결된 Instagram이 없을 때 OFF→ON은 막고 ON→OFF는 허용한다.
4. 저장 중 중복 조작을 막고 실패 시 상태를 유지하며 오류를 표시한다.
5. `수정` 버튼이 기존 팝업을 열고 닫힌 뒤 포커스를 복원한다.
6. 팝업에는 활성화 스위치가 없고 시간·형식 저장이 enabled 상태를 보존한다.
7. 설정 조회 실패 시 토글은 비활성화되고 `수정` 버튼은 읽기 전용 오류 팝업을 연다.

관련 게시관리 테스트, 고객 UI 전체 테스트, 타입 검사와 빌드를 통과해야 완료로 판단한다.

## 제외 사항

- 활성화 전용 PATCH API 추가
- DB migration
- 자동 배정 시간이나 추천 정책 변경
- 기존 예약 취소 또는 재배정
- 목록형 게시관리 UI 변경
- 운영 배포
