# D 하이브리드 실행 가능 회귀 매트릭스

- 기준 보존표: `docs/prd/brand-pilot-feature-preservation-ledger.md`
- `생명주기`는 제품 구현 상태가 아니라 현재 자동 증빙 상태다.
  - `active`: 실제 파일과 test name이 연결되어 verifier가 둘 다 검사한다.
  - `planned`: 제품 요구사항은 보존되지만 정확한 자동 증빙이 없어 `GAP:`으로 공개한다.
  - `excluded`: 사용자 화면 제외를 negative UI/API test로 고정한다.
  - `superseded`: 기존 ID를 유지하고 대체 ID 링크를 남긴다.
- `E2E/Smoke`의 `수동:` 항목은 아직 자동화되었다고 주장하지 않는 실행 시나리오다.
- 이 문서는 구현 상태를 과장하지 않는다. `planned` 행도 보존표에서 삭제할 수 없으며 후속 회귀 Task가 증빙을 추가해야 한다.
