Operating Model

단계가 아니라 기반과 순환

브랜드 센터는 “1단계”가 아닙니다. 콘텐츠 생성, Instagram 고객응대, 성과 개선이 함께 참조하는 공통 기반입니다. 실제 마케팅 흐름만 탐색 → 제작 → 게시 → 학습으로 순환합니다.

브랜드 센터

AI가 원본을 분석해 초안을 채우고, 사용자가 검토·수정·승인한 정보만 실행 기준이 됩니다.

1

탐색·레퍼런스

트렌드, 참고 브랜드와 콘텐츠를 수집·분석해 검색 가능한 레퍼런스로 보관합니다.

2

기획·콘텐츠 제작

정보성·마케팅성 목적, 타깃, 전략, 형식을 정하고 정적 콘텐츠를 생성합니다.

3

검토·게시

브랜드 규칙과 사실을 검사하고 실제 지원되는 채널에 안전하게 게시합니다.

4

성과·학습

전략·형식·후크·소구점의 성과를 비교해 다음 콘텐츠 제안을 개선합니다.

↩ 성과와 최근 사용 이력이 다음 콘텐츠 제안으로 돌아갑니다

Instagram 고객응대 ↔ Wiki 개선

Brand Core·제품·Wiki에 근거해 자동답변하고, 지식이 부족한 질문은 사람 확인과 Wiki 개선 후보로 돌립니다.

지원·계정

고객센터, 피드백 팝업, 화면 도움말, 로그인과 사용량을 관리합니다.

관리자·운영

채널, 게시 복구, 워커, 감사 로그, 배포와 복원을 운영합니다.

Creation Flow

선택은 한 번, 추천은 계속

앞 단계의 선택은 레퍼런스 추천을 정교하게 만들지만 사용자가 여러 화면에서 같은 자료를 반복 선택하지는 않습니다. 현재 위저드의 STEP 4 단일 선택 구조를 보존하고 아바타와 역할 지정을 그 화면에 합칩니다.

STEP 1 콘텐츠 방향

정보성·마케팅성, 목적, 제작 형식

STEP 2 주제·제품 분석

주제, Wiki, 제품·서비스, 근거 자료

STEP 3 타깃·소구점·전략

타깃 최대 3개, 소구점, 메시지 전략 제안

STEP 4 · ONE TIME 레퍼런스·아바타

레퍼런스 0~5개, 역할, 아바타 0~1개

STEP 5 Brief·생성

추가 지시, CTA, 색상, 비율, 결과 수

확정 원칙: 생성 과정에서 레퍼런스·아바타 선택 화면은 정확히 한 번만 등장합니다. 선택하지 않고 Brand Core·제품·Wiki만으로 생성하는 것도 허용합니다.

Content Taxonomy

목적, 전략, 형식을 분리

`정보성/마케팅성`은 콘텐츠 계열, 문제 해결·후기·USP 등은 메시지 전략, 카드뉴스·블로그·단일 이미지는 제작 형식입니다. 카피는 모든 결과물의 출력 구조입니다.

정보성 콘텐츠

고객이 이해하고 판단하는 데 도움을 주며 신뢰와 저장 가치를 만듭니다.

문제 해결·사용법 비교·선택 가이드 FAQ·오해 해소 트렌드·시장 인사이트 사례·데이터

마케팅성 콘텐츠

제품·서비스의 검증된 효익을 특정 고객과 상황에 연결해 행동을 유도합니다.

고객 문제·사용 상황 효익·USP 후기·신뢰 대안 비교 프로모션·CTA 브랜드 스토리

Reference System

검색 가능한 영감, 분리된 사실

Feature Ledger

현재 코드와 목표 제품을 함께 보기

각 기능은 구현 상태, 운영 활성화, 이번 변경 판단을 따로 표시합니다. “코드가 있음”, “첫 배포에서 켜짐”, “사용자에게 노출함”은 서로 다른 사실입니다.

1. 구현 상태

구현 완료 · 부분 구현 · 신규 설계 · 기술 기반만 존재

2. 운영 활성화

사용 중 · 외부 설정 필요 · 첫 배포 비활성 · 구현 후 활성

3. 변경 판단

유지 · 이동 · 고도화 · 신규 · 사용자 화면 제외

현재 제품 범위에서 제외

아래 항목은 지금 만들지 않습니다. 기존 저장소에 관련 기술 기반이 있다면 삭제하지 않고 휴면 상태로 보존하되, 메뉴·자동 제안·생성 형식에서 현재 지원 기능처럼 노출하지 않습니다.

`/archive` 명칭 보정

현재는 생성 콘텐츠 보관함이 아니라 Instagram 트렌드 북마크입니다. 생성 결과 목록과 레퍼런스 보관함을 분리합니다.

채널 능력 보정

6개 채널 카탈로그와 실제 API 게시 능력을 분리합니다. 현재 실제 퍼블리셔는 Instagram 중심입니다.
