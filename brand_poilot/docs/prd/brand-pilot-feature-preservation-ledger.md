# Brand Pilot 기능 보존표

- 기준일: 2026-07-24
- 목적: 제품 구조를 정리하는 동안 기존 기능이 조용히 삭제되거나 과장 표시되지 않도록 하는 회귀 기준
- 범위: 고객 앱, API, 콘텐츠·게시·DM·Wiki 워커, 관리자, Ubuntu 배포

## 기본 보존 원칙

- 이 문서에서 `사용자 화면 제외` 또는 현재 범위 제외로 명시하지 않은 기존 기능은 기본적으로 보존한다.
- 화면 이동, 명칭 변경, 디자인 개편은 기능 삭제 승인으로 해석하지 않는다. 기존 API, 데이터 호환, 제한, 오류 처리, 상태, 관리자·운영 경로까지 함께 보존한다.
- 수치 제한은 서버 강제와 사용자 화면의 잔여량·오류 안내를 함께 검증한다. 환경값으로 조정할 수 있더라도 현재 기본값과 중복 차감 방지 규칙은 회귀 대상이다.
- 새 위치가 정해지지 않은 기능은 삭제하지 않고 `미배치` 상태로 남긴다.
- 기능 삭제나 비호환 변경은 이 표의 변경 판단을 먼저 갱신하고 사용자 승인을 받은 뒤 진행한다.

## 상태 읽는 법

세 축을 합치지 않는다.

| 축 | 값 | 의미 |
|---|---|---|
| 구현 상태 | 구현 완료 / 부분 구현 / 신규 설계 / 기술 기반만 존재 | 현재 코드에 존재하는 정도 |
| 운영 활성화 | 사용 중 / 외부 설정 필요 / 첫 배포 비활성 / 해당 없음 | 실제 운영 환경에서 켤 수 있는 상태 |
| 변경 판단 | 유지 / 이동 / 고도화 / 신규 / 사용자 화면 제외 | 이번 제품 정리에서의 결정 |

`부분 구현`은 실패나 삭제 대상이라는 뜻이 아니다. 화면, API, 워커, 외부 권한 중 일부만 준비되었거나 목표 구조와 연결이 더 필요한 상태다.

## 명칭과 화면 보정

### `/archive`

현재 `/archive`는 생성·게시 자산 보관함이 아니라 Instagram 트렌드 북마크다.

- 사용자 명칭: `트렌드·참고 콘텐츠` 또는 통합 후 `레퍼런스 보관함`
- 생성 결과: 기존 AI 콘텐츠 목록에서 관리
- 과거 URL: 호환 또는 리디렉션

### 채널

채널은 아래 세 상태를 구분해 표시한다.

1. 해당 채널용 콘텐츠를 생성·변환할 수 있음
2. 파일 또는 텍스트로 내보낼 수 있음
3. API로 실제 게시할 수 있음

채널 카탈로그에 존재한다는 이유로 실제 API 게시가 가능하다고 표시하지 않는다.

### 영상 코드

저장소에 Reel 관련 코드와 설계가 일부 있어도 이번 사용자 제품 범위에는 영상 제작을 포함하지 않는다.

- 메뉴, 생성 형식, 자동 제안에서 숨김
- 신규 영상 작업 생성 차단
- 기존 데이터가 있다면 삭제하지 않고 기술 기반으로 보존
- 정적 Instagram Story는 정적 이미지 게시 형식으로 유지
