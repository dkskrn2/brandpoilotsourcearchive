# Brand Pilot 로그인 링크 전환 설계

## 목표

Growthline 홈페이지의 데스크톱·모바일 헤더에 있는 비활성 `로그인` 버튼을 활성 링크로 바꾸고, 사용자가 현재 탭에서 Brand Pilot 로그인 화면으로 이동하게 한다.

## 동작

- 대상 URL: `https://app.danbammsg.co.kr/login`
- 데스크톱과 모바일 헤더에 동일하게 적용한다.
- 기존 `site-login` 클래스와 시각적 모양을 유지한다.
- 비활성 `button` 대신 실제 링크 요소를 사용해 키보드 탐색과 브라우저 기본 링크 동작을 보장한다.
- 새 탭은 열지 않으며 현재 탭에서 이동한다.

## 구현 범위

- `components/site-header.tsx`의 로그인 요소 두 곳을 변경한다.
- 로그인 링크에 접근 가능한 이름 `로그인`을 유지한다.
- 기존 홈페이지 메뉴와 관리자 로그인 경로는 변경하지 않는다.
- Brand Pilot 인증 로직이나 사용자 앱 코드는 변경하지 않는다.

## 검증

- 데스크톱·모바일 로그인 요소가 모두 링크인지 확인한다.
- 두 링크의 목적지가 정확한지 테스트한다.
- 프로젝트 테스트, 린트, 프로덕션 빌드를 실행한다.
- 기존 사용자 변경인 `app/layout.tsx`는 건드리지 않는다.
