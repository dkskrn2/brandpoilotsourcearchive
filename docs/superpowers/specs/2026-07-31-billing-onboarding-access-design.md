# Billing 온보딩 접근 허용 설계

## 목적

브랜드 프로필 온보딩이 완료되지 않은 사용자도 사이드바의 `결제 및 구독` 메뉴를 통해 `/billing` 페이지에 접근할 수 있게 한다.

## 변경 범위

- `isBrandSetupPath()`가 `/billing`을 설정 단계에서 접근 가능한 경로로 판정하게 한다.
- 콘텐츠 검토, 게시 관리, 소스, 채널 등 기존 보호 메뉴의 온보딩 잠금은 유지한다.
- Billing 라우트와 페이지 구현은 변경하지 않는다.

## 동작

온보딩 완료 여부와 관계없이 `/billing` 사이드바 항목은 활성 링크로 렌더링된다. 기존 `/onboarding`, `/brand-settings`, `/support` 접근 동작도 그대로 유지된다.

## 테스트

온보딩 미완료 상태에서 `isBrandSetupPath("/billing")`이 참을 반환하는 회귀 테스트를 먼저 추가한다. 기존 보호 경로가 잠금 대상이라는 테스트도 함께 유지하여 변경 범위를 검증한다.
