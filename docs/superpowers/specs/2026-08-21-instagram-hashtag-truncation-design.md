# Instagram 게시 해시태그 상한 처리 설계

## 목표

AI 콘텐츠가 5개를 초과하는 유효한 해시태그를 생성해도 게시 전체를 실패시키지 않고, Instagram 게시 요청에는 기존 순서의 앞 5개만 전달한다.

## 범위

- 게시 직전 `formatInstagramCaption`의 해시태그 정규화만 변경한다.
- 문자열 형식 검증과 중복 검증은 기존대로 전체 입력에 적용한다.
- 유효한 해시태그가 5개를 넘으면 검증 후 `slice(0, 5)`로 제한한다.
- 생성 결과, DB, 모델 프롬프트, API 계약, worker 및 이미지 자산은 변경하지 않는다.

## 오류 처리

- 배열이 아니거나 빈 값·잘못된 형식·중복이 있으면 기존 `instagram_caption_hashtags_invalid` 오류를 유지한다.
- 유효한 0~5개는 그대로 게시하고, 유효한 6개 이상은 앞 5개만 게시한다.

## 검증

- 운영 실패 건과 같은 유효한 7개 입력이 앞 5개로 변환되는 회귀 테스트를 추가한다.
- 기존 CTA, 단일 문단, 4개 및 5개 해시태그 테스트를 유지한다.
- API 타입 검사와 관련 테스트를 실행한다.
