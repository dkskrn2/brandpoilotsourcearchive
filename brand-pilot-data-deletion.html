사용자 데이터 삭제 안내

Brand Pilot 이용자는 계정, 브랜드 자료, 콘텐츠 초안, 외부 채널 연동 정보 등 서비스에 저장된 사용자 데이터의 삭제를 요청할 수 있습니다.

시행일: 2026년 7월 7일 · 운영자: GROWTHLINE · 삭제 요청: contact.html

1. 삭제 요청 방법

아래 방법 중 하나로 데이터 삭제를 요청할 수 있습니다.

  1. 문의 페이지에서 이름 또는 회사명, 연락처, Brand Pilot 계정 이메일, 삭제 요청 범위를 작성해 제출합니다.
  2. 서비스 내 계정 또는 워크스페이스 설정 화면이 제공되는 경우, 해당 화면에서 계정 삭제 또는 워크스페이스 삭제를 요청합니다.
  3. 외부 플랫폼 연동만 해제하려면 Brand Pilot의 채널 설정에서 해당 채널 연결을 해제합니다.
본인 확인과 오삭제 방지를 위해 계정 이메일, 연락 가능한 정보, 삭제 대상 워크스페이스 또는 브랜드명을 확인할 수 있습니다.

2. 삭제할 수 있는 데이터

  • Brand Pilot 계정 정보 및 프로필 정보
  • 브랜드명, 브랜드 설정, 콘텐츠 가이드, 캠페인 설정
  • 업로드한 이미지, 문서, 콘텐츠 초안, 게시 예약 데이터
  • 외부 채널 연결 정보, 접근 토큰, 페이지 또는 채널 ID
  • 서비스 이용 중 생성된 분석 설정, 자동화 설정, 알림 설정

3. 삭제 처리 기한

운영자는 삭제 요청을 접수한 뒤 본인 확인과 요청 범위 확인을 거쳐 지체 없이 처리합니다. 일반적인 삭제 요청은 영업일 기준 7일 이내 처리하며, 기술적 확인 또는 법적 검토가 필요한 경우 처리 일정과 사유를 안내합니다.

4. 보존될 수 있는 데이터

다음 정보는 관련 법령 준수, 분쟁 대응, 보안 감사, 요금 정산을 위해 필요한 기간 동안 분리 보관될 수 있습니다.

  • 계약, 결제, 세금계산서, 정산 관련 기록
  • 서비스 부정 이용, 보안 사고, 권리 침해와 관련된 기록
  • 전자상거래 등 관련 법령에서 보존을 요구하는 기록
  • 삭제 요청 처리 이력과 본인 확인에 필요한 최소 기록

5. 외부 플랫폼 데이터 삭제

Brand Pilot에서 외부 채널 연동을 해제하면 Brand Pilot이 보관한 연동 토큰과 연결 정보가 삭제됩니다. 다만 외부 플랫폼에 이미 게시된 콘텐츠, 댓글, 메시지, 통계 데이터는 해당 플랫폼의 정책과 도구를 통해 별도로 삭제해야 할 수 있습니다.

6. 백업 데이터

운영 백업에 포함된 데이터는 백업 보존 주기에 따라 순차적으로 삭제됩니다. 백업 데이터는 장애 복구 목적 외에는 사용하지 않으며, 복구 과정에서 삭제 요청 데이터가 되살아나는 경우 다시 삭제합니다.

7. 삭제 후 영향

  • 삭제된 계정과 브랜드 자료는 복구가 어려울 수 있습니다.
  • 게시 예약, 자동화, 채널 연동, 분석 기능이 중단됩니다.
  • 공동 작업자가 있는 워크스페이스의 경우 삭제 요청자의 권한 범위에 따라 일부 데이터만 삭제될 수 있습니다.

8. 문의

데이터 삭제, 연동 해제, 계정 탈퇴와 관련한 문의는 문의 페이지로 접수해 주세요.
